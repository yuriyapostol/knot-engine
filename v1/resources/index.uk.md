# Спільні ресурси

[Стандартний реєстр](standard.json) містить визначення `spatial-curve`, Grid X/O, мотузки, опори й карабіна. Це контракти типів, а не каталог перевірених вузлів. Core експортує ці самі дані як `STANDARD_RESOURCES`; передайте їх явно через `registries` або вкладіть потрібні визначення в об’єкті `KnotAsset`.

[Чинний контракт](../spec/knot-asset.uk.md) визначає реєстри, самостійні документи, конфлікти ID та розв’язання залежностей. Каталоги, категорії й додаткові формати потребують окремих перевірених визначень.

Ідентифікатори ресурсів незалежні від навігації й каталогу вихідних файлів. Перенесення документації не змінює простір імен `knot-engine`.
