# Початок роботи

Пакет надає `KnotViewer`, публічні типи даних, validators і resolvers. Інтерактивний редактор сайту — застосунок, який використовує ці експорти, а не інший засіб візуалізації.

## Запуск проєкту

```sh
npm ci
npm run dev
```

Відкрийте адресу з виводу команди, зазвичай `http://localhost:5173/`. Увесь двомовний сайт перебудовується й оновлюється після змін матеріалів, компонентів або прикладів. Для перегляду production-збірки використовуйте `npm run preview:site` на `http://localhost:5174/`.

## Використання компонента

Після встановлення пакета з локального tarball або опублікованої версії імпортуйте компонент і стилі:

```vue
<script setup lang="ts">
import { KnotViewer } from 'knot-engine'
import 'knot-engine/styles.css'
import asset from './open-rope.json'
</script>

<template>
  <KnotViewer :asset="asset" locale="uk" label="Мотузка" />
</template>
```

Використайте [`Asset` відкритої мотузки](../examples/assets/open-rope.json) як `open-rope.json`. Параметри вибору, події та методи знімків описані в [контракті компонента](../specifications/components.uk.md). Пакет використовує лише поточний контракт `Asset`. Статичне представлення вибирається через `representation-id`.
