# Початок роботи

Пакет надає `KnotViewer`, окремі 3D/мозаїчний переглядачі, сирі й підготовлені типи даних, валідатори та засоби розв’язання посилань. Інтерактивний редактор сайту — застосунок, який використовує ці експорти, а не інший засіб візуалізації.

## Запуск проєкту

```sh
npm ci
npm run dev
```

Відкрийте адресу з виводу команди, зазвичай `http://localhost:5173/`. Увесь двомовний сайт перебудовується й оновлюється після змін матеріалів, компонентів або прикладів. Для перегляду production-збірки використовуйте `npm run preview:site` на `http://localhost:5174/`.

## Використання компонента

Після встановлення пакета з локального tarball або опублікованої версії імпортуйте компонент і стилі:

```vue
<script setup lang="ts">
import { KnotViewer } from 'knot-engine'
import 'knot-engine/styles.css'
import knot from './open-rope.json'
</script>

<template>
  <KnotViewer :knot="knot" locale="uk" label="Мотузка" />
</template>
```

Використайте [`Knot` відкритої мотузки](../examples/knots/open-rope.json) як `open-rope.json`. Параметри вибору, події та методи знімків описані в [контракті компонента](../specifications/components.uk.md). Вибирайте статичне представлення через `representation-id`, коли підтримуваних представлень кілька. Без ID потрібне рівно одне підтримуване представлення. Для одного засобу відображення використовуйте окрему точку входу `knot-engine/3d` або `knot-engine/mosaic`.
