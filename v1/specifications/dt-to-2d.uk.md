# Перетворення DT → 2D

Ядро надає функції `convertDTToPD(input)` та `convertDTTo2D(input)`. Обидві — **явні операції**, незалежні від Vue-переглядачів.

Знаковий парний код Доукера—Тістлвейта задає обходи перетинів та визначає, чи непарний прохід іде знизу (від’ємне число). Але сам код не фіксує циклічний порядок усіх півребер. Конвертер перебирає можливі локальні порядки, перевіряє планарність отриманого PD-коду й передає його до `convertPDTo2D`.

```ts
import { convertDTTo2D, validateGeometry2D } from 'knot-engine'

const geometry = convertDTTo2D({
  convention: 'dt-signed-even',
  code: [4, 6, 2],
})
if (!validateGeometry2D(geometry).valid) throw new Error('Некоректна 2D-геометрія')
```

Наразі повний перебір обмежено **16 перетинами**. Це обмеження алгоритму, а не формату DT. Вхідні дані не змінюються. Результат — геометричне представлення `2d` з ламаними, яке можна зберегти у вузлі й передати переглядачу. Неявної конвертації всередині переглядачів немає.

Один DT-код може допускати кілька планарних реалізацій. Конвертер детерміновано обирає перший коректний порядок, але не гарантує канонічного зображення чи мінімуму вигинів.
