# Перетворення PD → 2D

Ядро експортує функцію `convertPDTo2D(code: PDCode): Geometry2DData`.

Конвертер перевіряє систему обертання PD, відновлює замкнені компоненти й будує планарну ламану. Для цього кожен перетин розгортається в чотири порти; отриманий граф вкладається за допомогою фіксованої опуклої зовнішньої межі та барицентричної релаксації. Перетин відновлюється з'єднанням протилежних портів через спільний центр. Упорядковані проходи зверху та знизу записуються в `crossings`.

Вхідні дані не змінюються. Компоненти без перетинів стають окремими замкненими кривими. Координати відносні та не відтворюють певного художнього вигляду вузла.

Наразі встановлено обмеження 256 перетинів для компонування. Використовуються ламані: автоматичне згладжування сплайнами могло б створити зайві перетини. Перед використанням результату перевіряйте його через `validateGeometry2D` і `locateCrossings`.

Приклад:

```ts
import { convertPDTo2D, validateGeometry2D } from 'knot-engine'

const geometry = convertPDTo2D({
  convention: 'pd-ccw-under-first',
  crossings: [[1,5,2,4],[3,1,4,6],[5,3,6,2]],
})
if (!validateGeometry2D(geometry).valid) throw new Error('Некоректна 2D-геометрія')
```
