# Представлення зображення

Вбудоване представлення `image` призначене для готових растрових і векторних файлів, а не для зберігання топології:

```json
{"mimeType":"image/svg+xml","src":"./images/trefoil.svg"}
```

`src` підтримує HTTPS, відносні шляхи та `data:` URL із відповідним MIME-типом. Файл завантажує браузер; обмеження міждоменного доступу можуть перешкоджати захопленню PNG. Зображення показує `KnotImageViewer`, а `KnotViewer` делегує йому відповідне представлення.

Схема даних: [image.schema.json](../schema/image.schema.json). Керування та знімки описано в [компонентах](components.uk.md).
