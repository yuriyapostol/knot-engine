# Перетворення PD → DT

`convertPDToDT(input)` перетворює перевірений планарний PD-код на знаковий парний код Доукера—Тістлвейта. Функція обходить компоненти, детерміновано вибирає початок нумерації з узгодженою парністю та зберігає проходження зверху/знизу. Вхідні дані не змінюються; геометрія не будується.

```ts
import { convertPDToDT, convertDTToPD } from 'knot-engine'
const dt = convertPDToDT({ convention: 'pd-ccw-under-first', crossings: [[1,5,2,4],[3,1,4,6],[5,3,6,2]] })
const pd = convertDTToPD(dt)
```

Перетворення **не є оберненими щодо буквального вмісту масивів**: можуть відрізнятися початкова точка, напрямок обходу, порядок компонентів, мітки перетинів і вибір планарного порядку. Порівнювати слід топологічну еквівалентність, а не JSON.

Поточний контракт знакового парного DT вимагає парної кількості проходжень перетинів для кожної компоненти та узгодженої глобальної парності. PD-діаграми поза цією підмножиною відхиляються з помилкою. Діаграми без перетинів цей конвертер не представляє. Зворотне DT → PD наразі обмежене 16 перетинами.
