# Представлення image та імпорт PLink

## Дані зображення

Вбудоване представлення `image` призначене для готових растрових і векторних файлів, а не для зберігання топології:

```json
{"mimeType":"image/svg+xml","src":"./images/trefoil.svg"}
```

`src` підтримує HTTPS, відносні шляхи та `data:` URL із відповідним MIME-типом. Файл завантажує браузер; обмеження міждоменного доступу можуть перешкоджати захопленню PNG. Зображення показує `KnotImageViewer`, а `KnotViewer` делегує йому відповідне представлення.

## Типи перетинів 2D

Проходження перетину в геометрії `2d` підтримує `classical` (також типово без поля `type`), `unknown` і `virtual`. Для класичного перетину використовують `underElement`/`overElement`, для інших — `otherElement`. Обидва проходження мають узгоджуватися за ідентифікатором і типом.

## Імпорт тексту PLink

PLink — **вхідний формат**, а не окремий тип представлення Knot. Використовуйте `knot-engine/core`:

```ts
import { parsePLinkProjection, importPLink2D } from 'knot-engine/core'

const source = `% Link Projection
2
0 1
2 3
4
0 0
10 10
0 10
10 0
2
0 1
2 3
1
0 1
-1`
const projection = parsePLinkProjection(source)
const data = importPLink2D(source)
// data — поле data представлення типу 2d у Knot.
```

`parsePLinkProjection` повертає вершини, напрямлені ребра, перетини та метадані компонентів. `importPLink2D` створює 2D-криві з ламаною інтерполяцією та впорядковані проходження перетинів, об'єднуючи послідовні ребра у відкриті чи замкнені криві. Заголовок `% Virtual Link Projection` підтримує префікси `r` і `v`.

Для перевірки реального файла прочитайте його **текст** у `source`, викличте `importPLink2D(source)`, додайте результат як `data` представлення `2d` і перегляньте через `Knot2DViewer` або `KnotViewer`. У поточній інтерактивній демоверсії немає окремого завантажувача файлів PLink. Експортовані з PLink SVG чи PNG **не є** текстовим форматом проєкції PLink.

Імпортер перевіряє формат та геометричні обмеження, але його не перевірено на великій незалежній добірці реальних файлів. Зворотний експорт у PLink і повне перетворення без втрат не реалізовано. Зокрема, перевіряйте самоперетини та орієнтацію компонентів, якщо важлива топологія.

Дослідження джерельних форматів: [представлення](../../design/representation-formats.uk.md).
