# knot-viewer

Незалежний Vue-компонент для інтерактивного перегляду моделей вузлів, побудованих із контрольних точок.

Самостійна бібліотека з підтримкою клієнтського та серверного рендерингу, настільних і сенсорних браузерів. Репозиторій також має містити окрему демонстраційну сторінку на Vite.

## Стан

Підготовлено специфікацію розробки 2026-09-27. Компонент, збірка пакета та демка ще не реалізовані. API та формат моделі нижче — запропонований контракт першої версії, який слід перевірити прототипом до стабілізації. Наявна LICENSE визначає ліцензію репозиторію; npm-ім'я й namespace ще не обрані.
