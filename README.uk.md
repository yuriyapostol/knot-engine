# knot-engine

[English](README.md) | [Українська](README.uk.md)

Пакет для моделювання та рендерингу вузлів із Vue 3 компонентом `KnotViewer`. Поточний `Knot` підтримує просторові криві, сіткові діаграми, мозаїчні діаграми, коди планарних діаграм, коди Даукера–Тістлетвейта, конструкції, стани, процедури й явні реєстри ресурсів. Компонент відображає статичні 3D-представлення, має перспективну/ортографічну камеру, SSR fallback та PNG.

## Локальний запуск

Потрібні Node 20.19+ та npm.

```sh
npm ci
npm run dev
```

Відкрийте URL, який виведе Vite. Команди перевірки:

```sh
npm run typecheck
npm test
npm run build
npm run build:example
npm run test:browser
npm run test:package
npm pack --dry-run
```

Щоб згенерувати PNG для картки, виконайте `npm run preview:model -- --model v1/examples/knots/twisted-loop.json --out /tmp/knot-preview.png`. Скрипт використовує локальний Chrome (або `CHROME_PATH`) і кешує результат за моделлю, розміром, браузером та версією засобу візуалізації.

Робоча назва пакета — `knot-engine`; реліз у npm ще не публікувався. Збірка бібліотеки міститься в `dist/`, а збірка демо — у `site-runtime-dist/`. Для збірки демо за підшляхом проєкту задайте `BASE_PATH=/your-path/`.

## Сайт GitHub Pages

Для локального перегляду всього сайту виконайте `npm run preview:site` та відкрийте `http://localhost:5174/`. Команда спочатку перебудовує сайт. `npm run dev` на порту `5173` запускає весь сайт і автоматично перебудовує його після змін.

`npm run build:site` збирає `site-dist/`: посібник `/v1/guide.html`, специфікації `/v1/specifications.html` зі схемами та прикладами, ресурси `/v1/resources.html` і проєктні матеріали `/design/index.html`. Інтерактивний редактор вбудовано у головну сторінку версії та посібник. Англійська — основна мова; адреси сторінок зберігають `.html`, а українські версії мають суфікс `.uk.html`, наприклад `/v1/guide/getting-started.uk.html` і `/design/architecture.uk.html`. Лінійка `v1` включає версії `0.x`. Архіви з `site/releases/` публікуються в `/releases/<версія-пакета>/`.

[Workflow Pages](.github/workflows/pages.yml) публікує весь сайт після push у `main` або ручного запуску на `main`, після перевірки типів і тестів. У **Settings → Pages** виберіть **GitHub Actions**. Стандартна адреса — [Knot Engine](https://yuriyapostol.github.io/knot-engine/).

`npm run site:archive` явно створює знімок поточної версії пакета. Перевірте та додайте його до релізного коміту; команда відмовляється перезаписувати наявний знімок. Звичайні збірки не створюють релізи й не змінюють версії. Докладніше: [архівування](site/README.uk.md), [політика публікації](design/publication.uk.md). Локальна збірка не розгортає сайт.

## Використання

```vue
<script setup lang="ts">
import { KnotViewer, type Knot } from 'knot-engine'
import 'knot-engine/styles.css'
defineProps<{ knot: Knot }>()
</script>

<template>
  <KnotViewer :knot="knot" label="Rope model" locale="en" />
</template>
```

Імпортуйте `Knot` і типи з `knot-engine/core`: ця точка входу не завантажує Vue, Three.js або DOM. Валідація повертає окремі `valid`, `complete`, `missingDependencies`, `uncheckedTypes`; показ вимагає повної перевірки. Невідомі поля відхиляються. Реєстри передаються явно, мережевого завантаження за URI немає.

`representation-id` вибирає статичне представлення; без нього використовується перше представлення просторових кривих. Конструкція містить предмети й стани, а процедура посилається на представлення. Анімації немає. Для оновлення геометрії замініть об’єкт `Knot`.

Методи: `resetView()`, `fitToView()`, `capture({width,height,view,transparent})`. PNG має типовий розмір 512×512 і максимум 2048×2048. Режими знімка — `current` і `model-preview`. Події: `ready({knotId,schemaVersion,warnings})`, `error`, `camera-change`. `initialCamera` приймає повний fit/fixed режим із перспективною або ортографічною проєкцією; FOV у радіанах.

[Контракт даних](v1/specifications/knot.uk.md) · [Функції](v1/specifications/functions.uk.md) · [Компонент](v1/specifications/components.uk.md) · [JSON Schema](v1/schema/knot.schema.json) · [Приклади](v1/examples/knots)

Оформлення використовує класи `.knot-engine-v1-viewer…` та наслідувані змінні `--knot-engine-v1-viewer-*`. Простір імен пакета містить мажорне покоління й назву компонента та дозволяє використовувати різні мажорні версії на одній сторінці; зворотна сумісність на початковій стадії не вимагається, включно з CSS. [Поточні змінні, типові значення та приклади](v1/specifications/components.uk.md#простір-імен-css-та-оформлення).

## Поточні обмеження

Автоматизовані перевірки охоплюють валідацію, геометрію, SSR/hydration, браузерне захоплення зображень і споживача tarball. Поведінка на реальних сенсорних пристроях та у WebView, мінімальні підтримувані версії peer-залежностей і генерація зображень на CI runner ще потребують перевірки. Браузерне захоплення використовує GPU-рендеринг, тому пікселі можуть відрізнятися між пристроями. Геометрія має просту поверхню мотузки та контур; вона не перевіряє фізичну правильність вузла.
